# Замена UI12/UI14 Apple IIgs на RP2350

[English README](README.md)

Экспериментальная замена ADB GLU **UI12** и контроллера клавиатуры **UI14**
одним модулем Waveshare Core2350B0. Это поведенческая эмуляция интерфейса,
а не выполнение оригинальной прошивки Mitsubishi. Дампов Apple ROM в проекте нет.

## Состояние на28 октября2026

- На Apple IIgs ROM01 подтверждены запуск, вход в Applesoft BASIC и его работа.
- Работают ADB-клавиатура: Command, стрелки, Enter, вызов меню
  Control+Command+Esc. Полная матрица символов ещё не проверена.
- Системный RESET сохраняет внутреннюю RAM UI14, поэтому тёплый сброс
  больше не превращается в повторную загрузку с диска.
- Светодиод GPIO39 горит, пока удерживается хотя бы одна распознанная клавиша.
- Watchdog с таймаутом2с проверяет оба ядра. Настоящее зависание каждого
  ядра в отдельности вызвало аппаратный перезапуск; Apple во время этих
  аварийных тестов был выключен.
- На более ранней версии получен System Good. Это не означает, что полный
  тест повторён на каждой последующей прошивке.

**Ограничения:** мышь, автоповтор, международные раскладки, загрузка с диска,
весь диапазон таймингов/IRQ и длительная непрерывная работа пока не проверены.
Поддерживается US-раскладка0. Для проверки контрольной суммы UI14 выдаются
синтетические данные, поэтому System Good не доказывает полной идентичности MCU.

## Подключение и прошивка

Использовался Core2350B0 с RP2350B, который сообщает ревизию кремния3 (A3).
Название модуля не равно ревизии кремния. A2 этим проектом не проверен.

Сначала прочитай [таблицу подключения](hardware/WIRING.md).
IRQ и RESET подключаются только через внешние транзисторы.
Сначала включать USB-питание Core, затем Apple; выключать в обратном порядке.
При USB-питании JP1 оставить разомкнутым. Не подавать5В на Core3V3.

Готовый файл: [iigs_combined.uf2](releases/2026-10-28/iigs_combined.uf2).
Для обновления переведи RP2350 в режим UF2 и скопируй туда файл.
Из работающей прошивки доступны USB-команды `DISARM`, затем `BOOT`.
ARM и опрос ADB включаются автоматически после успешного самотеста.
Если RP2350 перезапускался при работающем Apple, выполни системный RESET.

Клавиши:

- Control+Command+Esc — меню Desk Accessories.
- Control+Power/Reset — тёплый сброс, обычно вход/возврат в BASIC.
- Control+Command+Power/Reset — холодный запуск.

## Сборка и файлы

Команды сборки, зависимости и USB-диагностика описаны в [README.md](README.md).
Pico SDK2.3.1 загружается отдельно, Arm GNU toolchain ищется через PATH или
PICO_TOOLCHAIN_PATH. Личных абсолютных путей в скриптах нет.

- `firmware/` — исходники и сборка.
- `hardware/` — схема KiCad9, PDF, BOM и таблица проводов.
- `tests/` — тесты модели, клавиатуры и контроля watchdog.
- `docs/` — источники документации и реальные результаты проверок.
- `releases/` — проверенный UF2 и SHA256.

Готовой разведённой PCB и производственных Gerber в этом репозитории нет:
аппаратная часть представляет собой прототип на модуле с проводами.
Часы RTC — отдельный узел; их прошивка сюда не включена.
